🌦️ WEATHER RISK & OUTDOOR ACTIVITY PLANNER

Project Overview

The Weather Risk & Outdoor Activity Planner is a Python-based application designed to help users make informed decisions about outdoor activities using weather forecasts and risk assessments.

The application retrieves weather information for a selected location, evaluates potential weather risks and provides recommendations to help users plan their outdoor activities safely.

Project Objectives

* Retrieve real-time weather forecasts.
* Allow users to search for different locations.
* Analyse weather conditions and identify potential risks.
* Recommend suitable outdoor activities.
* Identify the best time for outdoor activities.
* Provide weather safety advice.
* Save weather history and favourite locations.
* Use AI to generate additional weather explanations and recommendations.

Installation

1. Clone the repository:

git clone YOUR_REPOSITORY_URL

2. Navigate into the project directory:

cd weather-risk-outdoor-activity-planner

3. Install dependencies:

pip install -r requirements.txt

4. Run the application:

streamlit run main.py
